A production dating platform built for the Nigerian market across mobile, web, administration, and marketing experiences.

## Product Ecosystem

The platform includes:

- React Native mobile application
- User-facing web application
- Role-based admin panel
- Marketing landing page
- Secure authentication and subscription workflows
- Real-time chat, notifications, filters, and feed features

## My Role

Full-Stack App Developer

I led the full-stack development and maintenance of the product across the mobile app, web app, admin panel, backend integrations, and landing page.

## Platforms Delivered

### Mobile Application
- User registration and OTP login
- Google authentication
- Profile creation and discovery
- Match and interaction workflows
- Real-time chat
- Push notifications
- Subscription and trial management
- Feed, filters, and engagement features

### Web Application
- Responsive browser-based user experience
- Authentication and profile access
- Feed and discovery workflows
- Messaging and account features


### Admin Panel
- User and profile management
- Content moderation
- Subscription and access controls
- Reports and activity review
- Platform configuration and analytics


### Landing Page
- Product positioning and value proposition
- Mobile app promotion
- Download and registration calls to action
- Responsive design for mobile and desktop

### App Url: https://professionaldating.net/

## Technology Stack

| Layer | Technology |
|---|---|
| Mobile App | Flutter |
| Web App | React  |
| Admin Panel | React  |
| Backend | Node.js and REST APIs |
| Database | MongoDB |
| Media Storage | Cloudinary |
| Real-Time Features | WebSockets |
| Authentication | OTP and Google Authentication |
| Hosting | Render |
| Notifications | Push notifications |

## Key Engineering Work

- Built secure authentication and role-based access
- Developed real-time chat and notification workflows
- Implemented subscriptions, trials, and access controls
- Designed user feeds, filters, and discovery experiences
- Migrated infrastructure from AWS to Render
- Optimized database, deployment, and media workflows
- Maintained production applications across mobile and web

## Results

- Supported approximately **40× user growth**
- Reduced cloud infrastructure costs by approximately **50%**
- Improved deployment reliability and production stability
- Delivered one connected product across mobile, web, admin, and landing experiences
